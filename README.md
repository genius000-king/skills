## مختبر

يجهّز الوكيل ملف HTML لتجربة قرارات التصميم والتخطيط: سؤال واحد، خياراته، ومعاينة واحدة. تجيب ثم تضغط «التالي»؛ ترتيب الأسئلة وفروعها يتبع المشروع وإجاباتك. الملاحظات والأدوات الإضافية تفتح عند الحاجة.

إطار المختبر دارك ثابت. المشروع القائم يحتفظ بهويته داخل المعاينة؛ المشروع الجديد يبدأ بالألوان والخطوط والتوجه. البدائل تعيد ترتيب محتوى الصفحة الفعلي، مع فرق واضح في البنية أو التفاعل.

![مختبر على الكمبيوتر](skills/mokhtabar/assets/images/mokhtabar-desktop.png)

### خريطة الصفحات

كانفس يعرض الصفحات بمصغرات فعلية وروابط ذات أسهم وتسميات للأفعال. يمكنك تحريك الصفحات والتكبير وفتح صفحة منفردة ومراجعة مواصفاتها وكتابة ملاحظة للوكيل. اختر قياس الجوال أو الكمبيوتر لتتغير أبعاد الصفحات نفسها.

## التثبيت والاستخدام

نزّل [حزمة مختبر](packages/mokhtabar-v4.0.0.zip)، ثم فكّ مجلد `mokhtabar` كاملًا في مسار مهارات وكيلك:

| الوكيل | المسار الشائع |
| --- | --- |
| Codex | `~/.agents/skills/mokhtabar/` |
| Claude Code | `~/.claude/skills/mokhtabar/` |
| غيرهما | مسار المهارات الذي توثقه الأداة |

```text
استخدم مختبر على [المشروع أو الفكرة].
جهّز الأسئلة المناسبة تلقائيًا، وطبّق البدائل على محتوى المشروع الفعلي.
أريد خريطة الصفحات وملاحظاتي ثم مواصفات التنفيذ القابلة للنسخ.
```

البناء يحتاج Python 3.10+ دون مكتبات إضافية. افتح ملف HTML في متصفح حديث؛ الموارد مضمنة للاستخدام دون اتصال.

```bash
git clone https://github.com/genius000-king/skills.git
cd skills
python skills/mokhtabar/scripts/build.py skills/mokhtabar/assets/example-project.json --out lab.html
```

مزيد من التفاصيل في [دليل المهارة](skills/mokhtabar/README.md) و[التثبيت](skills/mokhtabar/INSTALL.md).

## التنظيم

- `skills/`: تعليمات المهارات وقوالبها ومواردها.
- `packages/`: حزم مستقلة وبصمات SHA256.
- `docs/`: صور واجهة المختبر وعرض محايد.
- [catalog.json](catalog.json): فهرس المهارات.
- [CONTRIBUTING.md](CONTRIBUTING.md): طريقة إضافة مهارة أو تحديثها.

## حدود العرض

الأسئلة والفروع يجهّزها الوكيل مسبقًا؛ HTML لا يشغّل نموذج ذكاء اصطناعي داخله. المعاينة توضح التصميم والتنقل؛ تسجيل الدخول في المثال محاكاة انتقال وليس مصادقة فعلية. الموشن والفيديو يعرضان محاكاة ومواصفات ولا ينتجان ملف فيديو. الصور محايدة وتعرض الميزة؛ لا تتضمن مشاريع عملاء أو تقارير اختبار.
