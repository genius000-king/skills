## مختبر

ملف HTML لاختيار بدائل التصميم والتخطيط والتعليق عليها. المشروع القائم يحتفظ
بهويته؛ المشروع الجديد يبدأ بالألوان والخطوط والتوجه. التقسيم يظهر على الصفحات
الفعلية، مع خريطة تنقل ومواصفات وملاحظات لكل صفحة، ثم نص تنفيذ قابل للنسخ.

## التثبيت

نزّل ZIP وفكّه، ثم ضع مجلد `mokhtabar` كاملًا في مسار مهارات وكيلك:

| الوكيل | المسار الشائع |
| --- | --- |
| Codex | `~/.agents/skills/mokhtabar/` |
| Claude Code | `~/.claude/skills/mokhtabar/` |
| غيرهما | اتبع مسار المهارات المعتمد في الأداة |

البناء يحتاج Python 3.10+ دون مكتبات إضافية. العرض يحتاج متصفحًا حديثًا.

```text
استخدم مختبر على [المشروع أو الفكرة].
طبّق البدائل على محتوى الصفحات نفسه، واربطها بخريطة تنقل.
أريد ملاحظات الاختيارات والصفحات، ثم مواصفات التنفيذ.
```

```bash
git clone https://github.com/genius000-king/skills.git
```

## التنظيم

- `skills/`: المصدر والتعليمات والموارد لكل مهارة.

- [catalog.json](catalog.json): الفهرس. المتاح الآن مختبر فقط.
