# تثبيت مختبر

[العربية](INSTALL.md) · [English](INSTALL.en.md)

ضع مجلد `mokhtabar` كاملًا في مجلد المهارات الذي يدعمه وكيلك. لا تنسخ SKILL.md
وحده: القالب والسكربت والمثال جزء من المهارة.

- Codex: `~/.agents/skills/mokhtabar`
- Claude Code: `~/.claude/skills/mokhtabar`
- وكيل آخر: استعمل المسار الذي توثقه الأداة، أو اطلب منه قراءة SKILL.md مباشرة.

اطلب: «استخدم مختبر على مشروعي، وطبّق البدائل على صفحاته مع خريطة تنقل وملاحظات».

لبناء المثال المضمّن، من داخل هذا المجلد:

```bash
python scripts/build.py assets/example-project.json --out lab.html
```

افتح lab.html في المتصفح، اختر ودوّن ملاحظاتك، ثم اعتمد وانسخ النص النهائي إلى
الوكيل لتنفيذ المشروع. المهارة تحتاج Python 3.10+ للبناء ومتصفحًا حديثًا للعرض،
ولا تحتاج مكتبات إضافية أو حسابًا أو شبكة وقت الاستخدام.

اسمها «مختبر» ومعرّفها التقني `mokhtabar`. ملف SHELL.sha256 يحمي الإطار الأصلي
من التعديل بالخطأ. MIT للكود وSIL OFL لخطوط IBM Plex وNoto المضمّنة.
