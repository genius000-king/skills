# مراجع التصميم

- [Agent Skills specification](https://agentskills.io/specification): صيغة SKILL.md وتنظيم الموارد والسكربتات والتحميل عند الحاجة.
- [Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices): تعليمات واضحة ومختصرة، وقيود قابلة للتحقق، ومراجعة الاستخدام الفعلي.
- [MDN iframe srcdoc](https://developer.mozilla.org/en-US/docs/Web/API/HTMLIFrameElement/srcdoc): عرض HTML داخل iframe مع sandbox مستقل عن إطار المختبر.
- [MDN prefers-reduced-motion](https://developer.mozilla.org/en-US/docs/Web/CSS/@media/prefers-reduced-motion): احترام تفضيل المستخدم لتقليل الحركة.
- [IBM Plex](https://github.com/IBM/plex): الخط المضمّن ورخصته.

المبدأ الأساسي: المصدر الثابت يرسم إطار المختبر، وبيانات المشروع تغيّر محتوى المعاينة فقط. تبقى مراجعة جودة الأفكار والتفاعل مسؤولية الوكيل والمستخدم؛ فحص البيانات وحده لا يثبت جودة التصميم.
