# مختبر

مهارة لإنشاء ملف HTML يقارن بدائل التصميم والتخطيط، ويحفظ الاختيارات والملاحظات،
ويصدّر مواصفات التنفيذ. تدعم واجهات المواقع والتطبيقات والموشن والفيديو والشروح والخطط.

![واجهة مختبر](assets/images/mokhtabar-desktop.png)

## الإصدار 3

- شاشة اختيار مختصرة؛ الشرح والتضحية في تفاصيل مغلقة.
- المشروع القائم: المعاينة من مصدره، بألوانه وخطوطه ومحتواه.
- دون هوية: الألوان والخطوط والتوجه في بداية الأسئلة.
- التقسيم يعيد ترتيب عناصر الصفحة الفعلية. المصغرات تتبع الهوية الحالية.
- خريطة صفحات قابلة للسحب والتكبير، بأسهم توضح الإجراءات.
- فتح كل صفحة وحدها، ومواصفات وملاحظات مستقلة تحفظ وتصدر.
- مراحل وأسئلة متابعة، وملاحظات لكل خيار وفكرة خاصة وخطة تنفيذ.

![خريطة الصفحات](assets/images/mokhtabar-flow.png)

## الاستخدام

[نزّل ZIP](../../packages/mokhtabar-v3.0.0.zip)، وانقل مجلد `mokhtabar` كاملًا إلى
مسار مهارات وكيلك. تفاصيل المسارات في [INSTALL.md](INSTALL.md).

```text
استخدم مختبر لتعديل مشروعي القائم [المصدر والهدف].
حافظ على الهوية والمحتوى، وطبّق بدائل التقسيم على صفحات المشروع نفسها.
أريد خريطة تنقل، ومعاينات للجوال والكمبيوتر، وملاحظة لكل صفحة واختيار.
```

```text
استخدم مختبر لفكرة جديدة [الجمهور والهدف والقيود].
ابدأ بالألوان والخطوط والتوجه، ثم بنية الصفحات وتفاصيلها وتفاعلها.
```

داخل الملف: اختر المرحلة والبديل، افتح الصفحة أو خريطتها، وأضف ملاحظتك. اعتمد
بـEnter أو الزر، ثم انسخ النص أو نزّل الاختيارات لإرسالها للوكيل.

## البناء

```bash
python skills/mokhtabar/scripts/build.py project.json --out lab.html
python skills/mokhtabar/scripts/build.py project.json --selection choices.json --out lab.html
```

Python 3.10+ دون تبعيات، ومتصفح حديث. الوكيل يحتاج قراءة وكتابة الملفات؛ فحص مصدر
المشروع ومعاينته يحتاج أدوات مناسبة. الصيغة متوافقة مع Agent Skills، ولا تجعل
تطبيق محادثة بلا أدوات قادرًا على إنشاء الملفات أو فحص المواقع.

## المعاينة والحدود

ثيم المختبر ثابت، وهوية الصفحات مستقلة. القالب يعرض خيارات أعدّها الوكيل مسبقًا؛
لا يولد أسئلة جديدة داخل المتصفح. الفكرة المكتوبة تُرسل للوكيل ولا تُرسم تلقائيًا.
التنقل محاكاة للصفحات، والخدمات تُربط عند التنفيذ. الفيديو محاكاة CSS وليس تصدير MP4.
عند غياب المصدر وتوفر صورة فقط، يُبيّن أن المعاينة معاد بناؤها من المرجع.

الحفظ محلي على المتصفح. النص وJSON هما وسيلة إعادة الاختيارات للوكيل؛ لا تُرسل
الملاحظات إلى المحادثة تلقائيًا. صور العرض تستخدم محتوى محايدًا.
